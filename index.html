Tentang Diri

Halo! Nama saya Elfandy Mahardika, mahasiswa aktif di program studi Teknologi Informasi Universitas Brawijaya. Saat ini saya sedang mendalami pengembangan web khususnya menggunakan library ReactJS dan framework CSS Tailwind. Melalui proyek ini, saya belajar banyak mengenai pentingnya kolaborasi tim menggunakan Git dan GitHub, mulai dari manajemen branch hingga proses sinkronisasi kode. Saya memiliki ketertarikan yang besar dalam menciptakan antarmuka pengguna yang tidak hanya fungsional secara teknis, tetapi juga memiliki estetika desain yang baik dan responsif di berbagai perangkat. Sebagai mahasiswa kelas T2F yang berdomisili di Bogor, saya terbiasa bekerja secara daring dan mengedepankan komunikasi yang efektif dalam tim. Tujuan utama saya mengikuti mata kuliah ini adalah untuk mengasah kemampuan pemecahan masalah melalui pembangunan aplikasi nyata yang dapat memberikan manfaat bagi pengguna. Saya percaya bahwa integrasi antara desain kreatif dan logika pemrograman yang kuat adalah kunci masa depan industri teknologi. Selain berfokus pada aspek teknis dan akademis perkuliahan, saya juga menaruh perhatian besar pada optimalisasi perangkat keras dan eksplorasi automasi digital untuk meningkatkan produktivitas. Saya sangat percaya bahwa kombinasi antara pemahaman logika pemrograman yang sistematis dan kemauan untuk terus beradaptasi akan menjadi fondasi yang kokoh untuk perjalanan karier saya. Berdomisili di lingkungan yang kondusif di Malang, saya terus termotivasi untuk belajar hal-hal baru, berinovasi, dan berkontribusi secara nyata dalam pengembangan ekosistem teknologi informasi di Indonesia.
